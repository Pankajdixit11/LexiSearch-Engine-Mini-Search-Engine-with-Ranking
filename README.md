*** LexiSearch Engine ***

LexiSearch Engine is a mini search engine built in C++ using advanced Data Structures and Algorithms concepts such as Trie, Inverted Index, and Hash Maps.

It supports fast keyword searching, document indexing, prefix-based search, and ranked search results inspired by real-world search systems.

# Features

  Document Indexing  
  Fast Keyword Search  
  Ranked Search Results  
  Prefix Search using Trie  
  Case-Insensitive Search  
  Word Frequency Analysis  
  Efficient Inverted Indexing  

# Technologies Used

- C++
- STL
- Trie Data Structure
- HashMap (`unordered_map`)
- Sorting Algorithms
- String Processing
